# results/

Model results, one `.txt` file per country and scenario, named so that a
pattern in `config/results.md` matches them.

The files here now are synthetic placeholders for Country A, B and C
(codes XAA, XAB, XAC), written by `tools/make_placeholder_results.py`. They
are not model output and describe no real system. Delete them before adding
real results, so the two cannot be mixed.

Superseded runs go in `results/archive/`, which is never read.
